# Repository Overview

This repository hosts a simple **FastAPI-based machine learning inference service** built for the Iris dataset. It predicts the species of an Iris flower based on given measurements and demonstrates how to deploy an ML model using **Docker**, **Kubernetes**, and **GitHub Actions**.

🔗 **GitHub Repository:** [https://github.com/21f1000478mlops/mlops/tree/week-6](https://github.com/21f1000478mlops/mlops/tree/week-6)

---

## 📁 Files and Folders

### `.github/workflows/`

Contains automation scripts for **GitHub Actions**. These workflows handle continuous integration (CI) and continuous deployment (CD) tasks such as building Docker images and deploying to cloud or Kubernetes environments.

### `.ipynb_checkpoints/`

Auto-generated by Jupyter Notebooks to store temporary checkpoint data. Can be ignored for version control.

### `__pycache__/`

Stores Python bytecode files generated for faster script execution. Not required in repositories.

### `k8s/`

Holds **Kubernetes deployment files**, such as `deployment.yaml` and `service.yaml`. These define how the FastAPI app runs and exposes services in a Kubernetes cluster.

### `.dockerignore`

Specifies files and directories that should not be included during Docker image build to keep the image lightweight.

### `Dockerfile`

Defines the **Docker image** for the FastAPI service. It sets up dependencies, copies project files, and starts the Uvicorn server.

### `iris_fastapi.py`

Main **FastAPI application file**. Loads the machine learning model (`model.joblib`) and defines API routes (like `/predict`) to handle prediction requests.

### `model.joblib`

Contains the **trained scikit-learn model** for Iris classification. The model predicts flower species based on the four input parameters.

### `requirements.txt`

Lists the Python dependencies (like FastAPI, scikit-learn, and Uvicorn) required to run the service.

---

## ⚙️ How it Works

1. The API receives a POST request with flower features (`sepal_length`, `sepal_width`, `petal_length`, `petal_width`).
2. The FastAPI app loads `model.joblib` and performs prediction.
3. The response includes only the predicted class.

---

## 🚀 Deployment Options

* **Local:** Run directly using `uvicorn iris_fastapi:app --reload`
* **Docker:** Build and run using `docker build` and `docker run`
* **Kubernetes:** Deploy with YAML files inside `k8s/`
* **CI/CD:** Automate builds and deployments via `.github/workflows/`
